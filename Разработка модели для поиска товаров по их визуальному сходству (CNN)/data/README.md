# Данные проекта

Исходные файлы намеренно не лежат в репозитории.

## Откуда брать

Каталог из 140 изображений одежды и 50 запросов из учебного задания. Публичной версии нет. Файлы `images/` и `queries/` исключены из git через `.gitignore`.

## Как положить файлы сюда

Самый простой путь: скачать датасет и положить нужные файлы в корень папки проекта,
рядом с ноутбуком. Ноутбуки читают данные относительно своего расположения
(`pd.read_csv('train.csv')`), поэтому после запуска в папке появятся файлы,
которые `.gitignore` не пропустит в репозиторий.

## Скачивание из Kaggle

Этот датасет из учебного задания, публичной версии на Kaggle у него нет.
Варианты:

1. Скачать файлы из исходного задания и положить рядом с ноутбуком.
2. Загрузить датасет на Kaggle самому (Kaggle -> Datasets -> New Dataset),
   выставить лицензию, и тогда он станет доступен по ссылке `owner/slug`.
   Это лучший вариант для портфолио: снимается вопрос «откуда данные»
   и появляется ссылка, которую можно дать рекрутеру.
3. Оставить файлы в репозитории, если размер позволяет (здесь он небольшой).
