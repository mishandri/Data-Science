# Разработка модели для поиска товаров по их визуальному сходству (CNN)
Визуальный поиск товаров на основе сверточной нейросети

## Описание проекта
Данный проект решает задачу поиска визуально схожих товаров (одежды) в каталоге интернет-магазина. Для каждого изображения из папки queries находится наиболее похожий товар из папки images с использованием предобученной сверточной нейронной сети VGG16 и векторного поиска.

Цель - увеличить вероятность покупки и повысить лояльность пользователей за счет рекомендации визуально похожих товаров.

## Метрика
Accuracy: 0.72 (минимальное пороговое значение - 0.7)

## Используемые технологии
- PyTorch — глубокое обучение
- VGG16 (pretrained) — извлечение признаков
- Torchvision — трансформации изображений
- scikit-learn — косинусное сходство
- Pandas — обработка данных
- Matplotlib — визуализация результатов

## Структура данных
```
images/ — каталог с изображениями товаров (база для поиска)
queries/ — каталог с запросами (изображения, для которых ищутся аналоги)
result.csv — итоговый файл с предсказаниями (50 строк × 2 столбца)
```

### Процесс работы
1. Загрузка предобученной модели VGG16
2. Удаление последнего классификационного слоя (используется только feature extractor)
3. Применение аугментаций и нормализации к изображениям:
    - Resize до 224×224
    - Padding с отражением краев
    - RandomCrop
    - RandomHorizontalFlip
    - Нормализация (mean и std из ImageNet)
4. Извлечение векторов признаков для всех изображений из images
5. Для каждого запроса из queries:
    - Извлечение вектора признаков
    - Вычисление косинусного сходства с векторами из каталога
    - Исключение изображений с тем же ID (чтобы избежать поиска самого себя)
    - Выбор наиболее похожего товара
6. Сохранение результата в CSV-файл

### Визуализация
Для каждого запроса выводится пара изображений.

### Достигнутая точность
Accuracy: 0.72
