# Анализ клиентов кредитных карт с использованием методов кластеризации

Этот проект направлен на сегментацию клиентов банка на основе их поведения при использовании кредитной карты. Цель — выявить различные группы потребителей для дальнейшего анализа и возможной адаптации бизнес-стратегий.

## Обзор

В проекте используется набор данных **CC GENERAL**, который содержит информацию о транзакциях, балансах и других поведенческих факторах держателей кредитных карт. Основная задача — применить методы машинного обучения без учителя (кластеризацию) для выделения уникальных клиентских сегментов.

## Структура проекта


## Набор данных

* **Источник:** Данные загружены с Kaggle (`arjunbhasin2013/ccdata`).
* **Содержание:** Информация о 8950 клиентах, включает 17 признаков, таких как:
  * `BALANCE`: остаток на счете.
  * `PURCHASES`: общая сумма покупок.
  * `CASH_ADVANCE`: сумма снятых наличных.
  * `CREDIT_LIMIT`: кредитный лимит.
  * `PAYMENTS`: сумма платежей.
  * `TENURE`: срок владения картой (в месяцах).

## Этапы анализа

1. **Исследовательский анализ данных (EDA):**

   * Загрузка и первичный осмотр данных (`df.head()`, `df.info()`, `df.describe()`).
   * Обработка пропущенных значений (`MINIMUM_PAYMENTS` заполнены нулями, `CREDIT_LIMIT` — медианным значением).
2. **Предобработка:**

   * Стандартизация признаков для корректной работы алгоритмов кластеризации.
3. **Кластеризация:**

   * Использован основной алгоритм **DBSCAN**.
   * Выполнен подбор оптимальных параметров для обучения **DBSCAN**.

## Используемые библиотеки

* `pandas`, `numpy` - для обработки и анализа данных.
* `scikit-learn` - для масштабирования данных и алгоритмов кластеризации.
* `matplotlib`, `seaborn`, `plotly` - для визуализации результатов.

## Результаты

В результате работы кода клиентская база была разделена на несколько сегментов (кластеров). Анализ характеристик каждого кластера позволяет лучше понять структуру клиентуры и их финансовое поведение.

- `Silhouette Score = 0.391` говорит, что кластеры хорошо различимы, но не идеальны.
- `Calinski-Harabasz Index = 80.91` говорит, что это отличное разделение
- Высокий уровень шума (49%) - много выбросов
- Сильный дисбаланс кластеров (от 12 до 4479 точек)
- Один гигантский кластер + несколько мелких
- Качество кластеризации удовлетворительное для реальных данных. Параметры принимаются — они обеспечивают баланс между выделением структуры и выявлением аномалий.
- Выбранные параметры (`eps=0.9`, `min_samples=12`) принимаются как рабочие, поскольку они позволяют выделить содержательную структуру из `4` кластеров и идентифицировать аномалии.

Дальнейшее улучшение метрик приведёт к потере мелких кластеров и слиянию групп, что снизит практическую ценность результата.
