# Разработка товарных рекомендаций на основе ассоциативных правил

## Описание проекта

Данный проект реализует систему товарных рекомендаций для интернет-магазина фастфуда на основе ассоциативных правил. Система анализирует историю покупок и предлагает наиболее вероятный дополнительный товар к уже выбранному, что позволяет увеличить средний чек и глубину чека.

### Бизнес-ценность

- **Увеличить средний чек** - за счет рекомендации дополнительных товаров
- **Повысить глубину чека** - увеличить количество товаров в одной покупке
- **Улучшить пользовательский опыт** - предлагать релевантные товары на основе истории покупок
- **Оптимизировать кросс-продажи** - выявлять естественные товарные пары

## Архитектура решения

### 1. Загрузка и подготовка данных

Данные загружаются из CSV-файла, где каждая строка содержит идентификатор транзакции и название товара. Транзакции группируются по идентификатору, формируя список корзин покупок.

```python
transactions = df.groupby('transaction_id')['item_name'].apply(list).tolist()
```

### 2. Преобразование данных

Для применения алгоритма Apriori данные преобразуются в формат One-Hot Encoding с помощью TransactionEncoder:

```python
te = TransactionEncoder()
te_ary = te.fit_transform(transactions)
df_encoded = pd.DataFrame(te_ary, columns=te.columns_)
```

### 3. Поиск частых наборов

Алгоритм Apriori находит частые наборы товаров с минимальным порогом поддержки 0.05:

```python
frequent_itemsets = apriori(
    df=df_encoded,
    min_support=0.05,
    use_colnames=True
)
```

### 4. Генерация ассоциативных правил

На основе частых наборов генерируются ассоциативные правила с минимальным порогом уверенности 0.5:

```python
rules_apriori = association_rules(
    df=frequent_itemsets,
    metric='confidence',
    min_threshold=0.5,
    num_itemsets=len(transactions)
)
```

### 5. Предсказание

Для каждого товара из тестового набора:

- Ищутся правила, где этот товар является антецедентом (условием)
- Выбирается правило с наивысшей уверенностью (confidence)
- Если правило найдено, возвращается consequent (следствие) - рекомендуемый товар
- Если правило не найдено, возвращается значение по умолчанию ("Кола")
