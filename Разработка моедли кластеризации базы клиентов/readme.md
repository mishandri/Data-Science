# Разработка модели для кластеризации базы клиентов

## Описание проекта

В рамках проекта необходимо построить модель кластеризации для сегментации клиентов ресторана быстрого питания McDonald's. Модель должна разделить всех клиентов на 4 кластера и присвоить каждому клиенту метку (сегмент) наиболее репрезентативного клиента из предоставленного файла `exemplar.csv`.

## Цель

Создать модель, которая позволит ресторану определять маркетинговую стратегию для каждого клиента на основе выявленных архетипов. Результат — файл размерностью 1453 строки × 2 столбца (`id`, `Segment`) с минимальным значением метрики Accuracy ≥ 0.8.

## Исходные данные

* **mcdonalds.csv** — характеристики клиентов ресторана (1453 записи, 16 полей)
* **exemplar.csv** — ID эталонных клиентов, репрезентующих каждый из 4 кластеров

### Признаки клиентов:

| Категория                          | Поля                                                                                        |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **Восприятие бренда** | yummy, convenient, spicy, fattening, greasy, fast, cheap, tasty, expensive, healthy, disgusting |
| **Оценка**                      | Like (от -5 до +5)                                                                          |
| **Демография**              | Age, Gender                                                                                     |
| **Поведение**                | VisitFrequency, id                                                                              |

## Этапы обработки данных

### 1. Предобработка

* Преобразование поля `Like` из строкового формата в числовой
* Кодирование полей с `Yes`/`No` в бинарные значения (1/0)
* Кодирование `VisitFrequency` с помощью OrdinalEncoder
* Преобразование `Gender` в бинарный формат

### 2. Масштабирование

Для числовых признаков (`Like`, `Age`, `VisitFrequency`) применено **StandardScaler** для приведения к единому масштабу.

## Моделирование

### Выбор количества кластеров

Для определения оптимального числа кластеров использован **метод локтя** (Elbow Method). Диапазон: k = 1..8.

На основе графика выбрано **k = 4** кластера (согласно требованию задачи).

### Алгоритм кластеризации

Использован алгоритм **KMeans** с инициализацией центров на основе эталонных клиентов из exemplar.csv:

| Кластер | ID эталонного клиента |
| -------------- | -------------------------------------- |
| 0              | 681                                    |
| 1              | 628                                    |
| 2              | 907                                    |
| 3              | 1061                                   |

### Присвоение сегментов

После выполнения кластеризации каждому кластеру присвоена метка (`Segment`) соответствующего эталонного клиента.
